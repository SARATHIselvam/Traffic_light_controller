# 🚦 Traffic Light Controller using Verilog (FSM)

This project implements a **2-road traffic light controller** using **Verilog HDL** based on a **Moore Finite State Machine (FSM)** design approach. It is suitable for FPGA/ASIC learning and demonstrates good RTL design practices.

---

## 📌 Features

- Moore FSM with 4 states  
  - A Green  
  - A Yellow  
  - B Green  
  - B Yellow  
- Parameterized and clean state encoding using `localparam`
- Separate blocks for:
  - State register
  - Next-state logic
  - Output logic
- Timer-based state transitions
- Fully synthesizable RTL design
- ModelSim compatible testbench
